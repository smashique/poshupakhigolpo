# 🐾 পশুপাখি গল্প (PoshuPakhiGolpo.online)

**সোনামণিদের জন্য নিরাপদ, নৈতিক এবং শিক্ষামূলক গল্পের একটি জাদুকরী ভুবন।** এটি একটি আধুনিক **Progressive Web App (PWA)** যা শিশুদের শৈশবকে আনন্দময় করার পাশাপাশি নৈতিক শিক্ষায় শিক্ষিত করতে সাহায্য করে।

---

## 🚀 মূল ফিচারসমূহ (Key Features)

* **বাইল্যাঙ্গুয়াল কন্টেন্ট:** প্রতিটি গল্প বাংলা এবং ইংরেজি দুই ভাষায় পড়ার সুবিধা, যা শিশুদের ইংরেজি দক্ষতা বাড়াতে সহায়ক।
* **গ্যামিফিকেশন:** পড়ার সময় স্ক্রিনে ধীরগতিতে বেলুন উড়ে বেড়ায়, যা টাচ করলে পপ শব্দে ফেটে যায়—শিশুদের মনোযোগ ধরে রাখার জন্য একটি চমৎকার কৌশল।
* **স্মার্ট পেমেন্ট গেটওয়ে:** ২০% প্রিভিউ দেখার পর আজীবন মেম্বারশিপের জন্য 'উদ্ধোক্তাপেশ' (UddoktaPay) ইন্টিগ্রেশন।
* **PWA সাপোর্ট:** সরাসরি ব্রাউজার থেকে অ্যাপ হিসেবে ইন্সটল করার সুবিধা এবং হোমস্ক্রিনে শর্টকাট আইকন।
* **ফুল-স্ক্রিন মোড:** বড় পর্দায় নিরবচ্ছিন্নভাবে গল্প পড়ার অভিজ্ঞতা।
* **সোশ্যাল প্রুফ:** কতজন সচেতন অভিভাবক মেম্বারশিপ নিয়েছেন তার লাইভ কাউন্টার।

---

## 🛠 টেকনিক্যাল স্ট্যাক (Technical Stack)

* **Frontend:** HTML5, CSS3 (Custom Animations), JavaScript (ES6+).
* **Backend & Database:** [Supabase](https://supabase.com/) (Real-time data fetching & User status management).
* **Audio Engine:** Web Audio API (No external assets required).
* **Installation:** PWA with Service Worker (`sw.js`).

---

## 📂 ফাইল স্ট্রাকচার (File Structure)

* `index.html`: মূল ড্যাশবোর্ড এবং প্লেয়ার স্ট্রাকচার।
* `app.js`: অ্যাপের মূল ইঞ্জিন (সুপাবেস লজিক, সাউন্ড এবং গ্যামিফিকেশন)।
* `style.css`: ডিজাইন, রেসপন্সিভ লেআউট এবং বেলুন অ্যানিমেশন।
* `manifest.json`: PWA কনফিগারেশন এবং আইকন সেটআপ।
* `payment.html`: মেম্বারশিপ আনলক করার পেজ।
* `logo.png`: ব্র্যান্ডের অফিসিয়াল লোগো।
* `sw.js`: অফলাইন ক্যাশিং ও সার্ভিস ওয়ার্কার।
